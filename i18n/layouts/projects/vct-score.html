01 / {{ if $isVi }}TỔNG QUAN{{ else }}OVERVIEW{{ end }}

{{ if $isVi }}Một luồng vận hành
liền mạch.{{ else }}One connected
operational flow.{{ end }}

{{ if $isVi }}VCT Score kết nối những người tham gia trong một giải đấu: khách truy cập theo dõi thông tin công khai, võ sinh duy trì hồ sơ, trọng tài chấm điểm trận và quản trị viên điều phối toàn bộ dữ liệu.{{ else }}VCT Score connects everyone involved in a tournament: visitors follow public information, martial artists maintain their profiles, referees score matches, and administrators coordinate all data.{{ end }}

02 / {{ if $isVi }}QUY TRÌNH{{ else }}WORKFLOW{{ end }}

{{ if $isVi }}Từ giải đấu
đến kết quả.{{ else }}From tournament
to result.{{ end }}

  1. 01

    {{ if $isVi }}Khởi tạo dữ liệu{{ else }}Set up data{{ end }}

    {{ if $isVi }}Admin tạo giải; người dùng đăng ký, cập nhật hồ sơ võ sinh và xác định loại hình thi đấu.{{ else }}Admins create tournaments; users register, update martial-artist profiles, and define the competition type.{{ end }}

  2. 02

    {{ if $isVi }}Lập sơ đồ thi đấu{{ else }}Plan the bracket{{ end }}

    {{ if $isVi }}Chọn giải, thể thức loại trực tiếp hoặc vòng tròn, vận động viên, hạng cân, sân, trọng tài, thời điểm và khoảng cách giữa các trận.{{ else }}Select the tournament, knockout or round-robin format, competitors, weight class, venue, referee, start time, and interval between matches.{{ end }}

  3. 03

    {{ if $isVi }}Sinh lịch trận{{ else }}Generate the schedule{{ end }}

    {{ if $isVi }}Hệ thống tạo cặp đấu, sắp xếp thời gian và lưu mã trận, vòng đấu cùng trạng thái trận.{{ else }}The system generates matchups, schedules their times, and saves each match code, round, and status.{{ end }}

  4. 04

    {{ if $isVi }}Theo dõi công khai{{ else }}Follow publicly{{ end }}

    {{ if $isVi }}Người dùng xem lịch, thông tin hai võ sĩ và tỷ lệ dự đoán; thao tác chấm điểm chỉ hiển thị khi có quyền.{{ else }}Users view schedules, both competitors' information, and prediction rates; scoring controls appear only with permission.{{ end }}

  5. 05

    {{ if $isVi }}Chấm điểm trận đấu{{ else }}Score the match{{ end }}

    {{ if $isVi }}Trọng tài theo dõi đồng hồ hiệp, cộng hoặc trừ điểm, chọn phương thức kết thúc và gửi kết quả.{{ else }}Referees run the round timer, adjust points, choose an ending method, and submit the result.{{ end }}

  6. 06

    {{ if $isVi }}Cập nhật kết quả{{ else }}Update results{{ end }}

    {{ if $isVi }}Hệ thống lưu điểm, xác định thắng/thua, đổi trạng thái đã chấm và cập nhật danh sách kết quả.{{ else }}The system saves scores, determines wins and losses, marks the match as scored, and updates the result list.{{ end }}

  7. 07

    {{ if $isVi }}Xếp hạng & dự đoán{{ else }}Rank & predict{{ end }}

    {{ if $isVi }}Dữ liệu trận phục vụ tra cứu, thống kê, ranking và mô hình ML.NET dự đoán kết quả tham khảo.{{ else }}Match data supports lookup, reporting, rankings, and ML.NET reference outcome predictions.{{ end }}

  8. 08

    {{ if $isVi }}Truyền thông{{ else }}Communicate{{ end }}

    {{ if $isVi }}Admin tạo, xuất bản và đặt thời hạn hiển thị tin tức; người dùng đọc tin tại trang công khai.{{ else }}Admins create, publish, and set the visibility period for news; users read it on public pages.{{ end }}

04 / {{ if $isVi }}TRỌNG TÂM{{ else }}CORE MODULE{{ end }}

{{ if $isVi }}Chấm điểm
theo thời gian thực.{{ else }}Score
in real time.{{ end }}

{{ if $isVi }}Màn hình chấm điểm đưa các dữ liệu cần thiết về một nơi: đồng hồ hiệp, hồ sơ hai võ sĩ, điểm hiện tại và các thao tác xử lý kết quả. Điều này giúp trọng tài tập trung vào diễn biến trận đấu.{{ else }}The scoring screen brings the needed information together: round timer, both competitors' profiles, current score, and result controls. It lets referees focus on the match.{{ end }}

  • {{ if $isVi }}Đồng hồ hiệp với bắt đầu, tạm dừng và đặt lại.{{ else }}Round timer with start, pause, and reset.{{ end }}
  • {{ if $isVi }}Cộng/trừ điểm và cảnh cáo cho từng võ sĩ.{{ else }}Per-competitor score adjustments and warnings.{{ end }}
  • {{ if $isVi }}Ghi nhận TD-TH, WO, KO, DISQ, Ưu thế hoặc RSC.{{ else }}Record TD-TH, WO, KO, DISQ, Advantage, or RSC.{{ end }}
  • {{ if $isVi }}Lưu kết quả và chuyển dữ liệu sang module kết quả/ranking.{{ else }}Save results and pass data to results/ranking.{{ end }}

05 / {{ if $isVi }}VẬN HÀNH & DỮ LIỆU{{ else }}OPERATIONS & DATA{{ end }}

01

{{ if $isVi }}Quản trị tập trung{{ else }}Central administration{{ end }}

{{ if $isVi }}Khu vực admin quản lý người dùng, giải đấu, sơ đồ, trận đấu, kết quả và tin tức.{{ else }}The admin area manages users, tournaments, brackets, matches, results, and news.{{ end }}

02

{{ if $isVi }}Kết quả & ranking{{ else }}Results & ranking{{ end }}

{{ if $isVi }}Kết quả đã chấm là dữ liệu đầu vào cho tra cứu, thống kê và xếp hạng; với nội dung Đối Kháng, hệ thống có thể sử dụng kết quả để cập nhật Elo/ranking.{{ else }}Scored results feed lookup, reporting, and rankings; for sparring, the system can use outcomes to update Elo/ranking.{{ end }}

03
