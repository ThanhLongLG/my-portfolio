Learning data remains local, and AI content must be validated before it is shown.{{ end }}

04 / {{ if $isVi }}HỌC CHỦ ĐỘNG{{ else }}ACTIVE LEARNING{{ end }}

{{ if $isVi }}Từ vựng đi vào
bài viết thực tế.{{ else }}Vocabulary moves
into real writing.{{ end }}

{{ if $isVi }}Vocabulary không chỉ là flashcard. Mỗi mục học chứa nghĩa theo ngữ cảnh, phát âm, ví dụ, word family, collocations và bộ khoảng 10 bài tập. Sau các mốc từ vựng theo chủ đề, hệ thống đề xuất Writing để người học dùng lại từ trong ngữ cảnh.{{ else }}Vocabulary is more than flashcards. Each learning item contains contextual meaning, pronunciation, examples, word families, collocations, and a set of around 10 exercises. At topic vocabulary milestones, the app proposes Writing so learners reuse the words in context.{{ end }}

  • {{ if $isVi }}Tối đa năm mục từ mới được đề xuất mỗi ngày để tránh quá tải.{{ else }}At most five new vocabulary items are suggested each day to avoid overload.{{ end }}
  • {{ if $isVi }}Bài đầu cần đạt tối thiểu 8/10, kèm câu tự viết đạt yêu cầu.{{ else }}The first exercise needs at least 8/10, including a successful self-written sentence.{{ end }}
  • {{ if $isVi }}SRS đưa từ trở lại ở các mốc 1, 3, 7, 14 và 30 ngày.{{ else }}SRS returns items at 1, 3, 7, 14, and 30 days.{{ end }}
  • {{ if $isVi }}Writing chấm theo bốn tiêu chí IELTS và khuyến khích tự sửa trước khi xem mẫu.{{ else }}Writing is assessed against four IELTS criteria and encourages revision before showing a model.{{ end }}
