Smart Scoring System for Vietnamese Traditional Martial Arts

Ứng dụng web xây dựng theo kiến trúc MVC để quản lý giải đấu võ thuật, vận động viên, chấm điểm trận đấu, đăng ký trực tuyến, xếp hạng người chơi theo hệ thống ELO và các nghiệp vụ cốt lõi khác của giải đấu.

Công nghệ: ASP.NET Core MVC, C#, SQL Server, JavaScript, ML.NET.

Vai trò: Lập trình viên Full-stack

Trách nhiệm / Thành tựu:
  • Thiết kế và phát triển hệ thống quản lý giải đấu bằng ASP.NET Core MVC.

  • Triển khai thuật toán xếp hạng ELO và tự động cập nhật thứ hạng người chơi.
