02 / CASE STUDY

VCT
Score.

A web system for Vietnamese Traditional Martial Arts tournaments — from tournament setup and bracket planning to scoring and published results.

Full-stack Developer

01 / OVERVIEW

One connected
operational flow.

VCT Score connects everyone involved in a tournament: visitors follow public information, martial artists maintain their profiles, referees score matches, and administrators coordinate all data.

The design focuses on clear data and consistent match state, keeping schedules, scores, results, rankings, and public communications connected in one system.

ASP.NET CORE MVCC#JAVASCRIPTSQL SERVER / ORACLEML.NET

02 / WORKFLOW

From tournament
to result.

  1. 01

    Set up data

    Admins create tournaments; users register, update martial-artist profiles, and define the competition type.

  2. 02

    Plan the bracket

    Select the tournament, knockout or round-robin format, competitors, weight class, venue, referee, start time, and interval between matches.

  3. 03

    Generate the schedule

    The system generates matchups, schedules their times, and saves each match code, round, and status.

  4. 04

    Follow publicly

    Users view schedules, both competitors' information, and prediction rates; scoring controls appear only with permission.

  5. 05

    Score the match

    Referees run the round timer, adjust points, choose an ending method, and submit the result.

  6. 06

    Update results

    The system saves scores, determines wins and losses, marks the match as scored, and updates the result list.

  7. 07

    Rank & predict

    Match data supports lookup, reporting, rankings, and ML.NET reference outcome predictions.

  8. 08

    Communicate

    Admins create, publish, and set the visibility period for news; users read it on public pages.

03 / INTERFACES

The right information,
at the right moment.

04 / CORE MODULE

Score
in real time.

The scoring screen brings the needed information together: round timer, both competitors' profiles, current score, and result controls. It lets referees focus on the match.

  • Round timer with start, pause, and reset.
  • Per-competitor score adjustments and warnings.
  • Record TD-TH, WO, KO, DISQ, Advantage, or RSC.
  • Save results and pass data to results/ranking.

05 / OPERATIONS & DATA

01

Central administration

The admin area manages users, tournaments, brackets, matches, results, and news.

02

Results & ranking

Scored results feed lookup, reporting, and rankings; for sparring, the system can use outcomes to update Elo/ranking.

03

Reference predictions

ML.NET analyses available match and ranking data to display reference win probabilities; it never replaces the actual decision.
